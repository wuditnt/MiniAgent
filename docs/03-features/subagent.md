# 子智能体（委派）

## 用途

把一个自包含的调查类子任务交给**只读**子代理执行，只把结论带回主对话，中间过程不占主上下文。

## 概念

- **独立上下文**：子代理有独立的消息上下文，不带主对话历史。
- **只读工具子集**：没有写文件 / 执行命令 / 提问 / 再派子代理。
- **只回三样**：结论 + 证据 + 未决；结果超 2000 字截断。
- **并发**：一轮可并发派多个。
- **停止传导**：父任务停止时子代理一起停。
- **降级**：超时（默认 120s）或模型异常降级成可读失败文本，不中断整轮。

## 使用方式

- 智能体模式下由模型自行决定是否调用 `delegate`；无需用户手动操作。
- 开关、子任务轮次与超时在「通用配置」里调。
- 任务过于笼统或深度超限时由 `should_delegate` 直接否决。
- 写入 / 执行 / 交互类任务由工具描述约束模型不要派；即使误派，子代理也没有这些工具，改不了文件。

## 适合与不适合

| 适合 | 不适合 |
|---|---|
| 只读调查、资料核对、多文件检索汇总 | 写文件、改代码、执行命令 |
| 需要大量中间步骤但只关心结论 | 需要用户确认或提问的任务 |
| 可与主任务并行的独立子问题 | 依赖主对话细节的后续操作 |

## 关键代码位置

- 实现：`src/core/subagent.py` 的 `SubagentResult`、`build_registry()`、`run_subagent()`、`should_delegate()`、`delegate()`、`register()`
- 配置读取：`_limits()`（`subagent_max_turns` / `subagent_timeout`）
- 提示注入：`src/core/agent.py` 的 `_delegate_nudge()`
- 测试：`tests/test_subagent.py`（任务包隔离 / 只读子集 / 结果截断 / 取消传导 / 超时 / 开关 / 委派提醒）

## 注意事项

- 子代理是只读的，这是硬约束，不靠提示词自律。
- 子代理结果有长度上限；需要完整明细的任务应在主对话里做。
- 委派会额外消耗一次模型调用，简单任务不值得派。
- 子代理失败不会让主任务失败，会以可读失败文本返回。
