# skills_user —— 你自己的技能放这里

## 一个 skill 是什么

一个目录 + 一张 `SKILL.md`。目录名就是默认的技能名，`SKILL.md` 顶部可用
YAML frontmatter 覆盖名字和一句话描述，正文是给模型的完整操作指引。

```
my-skill/
  SKILL.md
  （可选：脚本、资源等辅助文件）
```

## 三条约定

1. 目录名**不要**以 `.` 或 `_` 开头（会被忽略）
2. `SKILL.md` 的 frontmatter 里写 `name` 和 `description`：
   ```markdown
   ---
   name: my-skill
   description: 什么时候该用这个技能
   ---

   # 完整的操作步骤……
   ```
3. 改完不用重启，控制台里敲 `/skills reload` 即可重新扫描

> `description` 决定模型**何时**用你的技能 —— 它会进 system prompt 的清单里，
> 写清楚「在什么情况下用」，而不是只写个名字。

## 技能和工具有什么区别

- **工具**是模型能*调用*的能力（一次函数调用，输入输出）
- **技能**是模型能*遵循*的工作流（一段指令，通常会编排多个工具）

模型平时只看到技能的一句话清单（不占上下文），判断任务命中后才调用
`use_skill` 工具把完整正文拉进来 —— 所以技能写再长也不会拖慢不相关的任务。
